# 课程拓展方向与学术边界

基础作业的共同目标是：从自然语言和视觉观测出发，完成桌面物体的抓取、放置或分拣，并用物理成功谓词与过程日志证明系统真的形成了闭环。完成基础要求后，可选择以下方向做加分拓展。

## A. VLA 路线

用视觉—语言—动作（VLA）模型直接或分层地产生末端增量、抓取候选或关节目标。推荐保留项目已有的安全骨架：动作限幅、`CartesianDeltaAdapter` / 数值 IK、异步请求、状态过期丢弃、验证与失败恢复。报告应说明模型输入、动作表示、控制频率、延迟处理、失败案例，以及与 VLM+几何基线的可复现实验对比。

## B. 人形机器人平台路线

将同一类“语言指定对象—视觉定位—安全接近—抓取—验证”的闭环迁移到人形机器人平台。可以把移动、双臂协同、相机视角变化、人体安全距离和真实执行延迟作为额外难点，但必须保留可复现的任务定义和成功条件。若真实硬件资源有限，可提交仿真到真机的接口设计、受控录像和与本项目相同的日志协议；不要只展示单段剪辑视频。

## C. 课程内自选

也可结合本课程内容提出主题相近的拓展，例如多视角主动感知、语言歧义澄清、抓取失败后的恢复、跨物体泛化、安全门控或评测/消融设计。开始前应在项目 README 写清：任务、观测、动作、成功谓词、对照实验和风险控制。

## 不接受的拓展

1. **偏离课程主题。** 题目必须仍以具身抓取/操控中的语言、视觉、规划、控制、验证或评测为核心，不能把作业改成与抓取闭环关系很弱的纯文本 Agent、纯图像分类、网页系统或无执行验证的展示。
2. **搬运已有投稿工作。** 不接受把学生或团队已准备投稿、正在投稿或已经投稿的研究工作直接拿来讲解或充当课程成果。课程鼓励在课程周期内产生的新结果；若使用公开基线、开源模型或已发表工作，必须清楚引用，并展示由本课程任务、代码和实验产生的新增实现与证据。

对自选题，建议在实现前提交一页任务设计说明，由教师确认范围。评分仍以基础闭环、复现性、证据质量和诚实边界为准，而不是模型规模、硬件价格或视频观感。
