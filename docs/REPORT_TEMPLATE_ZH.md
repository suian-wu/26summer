# 实验报告模板

## 1. 问题定义与边界

任务、观测、动作、成功、失败、安全约束；明确是否使用外部 API、预训练权重或额外数据。

## 2. 系统架构

画出信息流和控制频率；列每个模块输入/输出 schema、运行位置、版本、超时和回退。若使用远端模型，
还要列异步 worker、命令复用窗口、安全保持条件、状态过期门限和延迟分布。

## 3. 方法

目标 grounding；真实模型 endpoint 与请求/响应 schema；mask/box/point 证据；坐标/几何；
IK/规划/VLA；夹爪控制；状态机/Agent；动作后验证与恢复。明确模型失败时是否存在回退。

## 4. 实验设计

公开/自建/隐藏切分；seed；重复次数；冻结项；主要指标；baseline；控制变量与消融。

## 5. 结果

至少报告 success rate、target accuracy、steps/time、retry、安全接触、非目标扰动；
给总体表和按物体/语言/难度分桶表。

## 6. 失败分析

给代表性事件日志和时间线；区分最早错误点与最终现象；给出感知、规划、控制、验证占比。

## 7. 讨论与边界

仿真与真实机器人差异；API/模型成本；哪些结论不能推广；下一步最有价值的改进。

## 8. 可复现性

机器、OS、Python、依赖、命令、配置、prompt/权重版本、随机种子、运行时间。

## 9. 团队分工

逐人列出可核查代码、实验、报告、演示贡献，并说明共同完成部分。
