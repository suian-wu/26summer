# 键盘遥控：认识环境和控制接口

`scripts/view_teleop_gpu.py` 是课程提供的**人工遥控起步工具**。它不调用 VLM、SAM 或任何真值目标信息；操作者只通过相机画面理解场景，用键盘向数值 IK 发出受限的末端增量。它适合熟悉夹爪、碰撞、物体形状和评测场景，不能作为提交的自动策略或评测结果。

## 启动

在有图形桌面或 VNC 的服务器中运行：

```bash
cd mujoco-grasp-assignment
source .venv/bin/activate
DISPLAY=:57 MUJOCO_GL=egl python scripts/view_teleop_gpu.py --task-set task1
```

`DISPLAY=:57` 只是课程演示机示例；本地电脑不需要填写，VNC 使用其他 display 时替换它。MuJoCo 画面由 EGL/GPU 渲染，Tk 窗口只负责把完成的 RGB 帧交给 VNC 显示。连接到 VNC 后先单击窗口，再按键操作。

## 键位与安全边界

| 按键 | 操作 |
|---|---|
| `W` / `S` | 末端前进 / 后退 |
| `A` / `D` | 末端左移 / 右移 |
| `R` / `F` | 末端上移 / 下移 |
| `Q` / `E` | 末端绕竖直方向偏航 |
| `Space` | 切换夹爪张开 / 闭合 |
| `H` | 使用同一随机任务重置场景 |
| `N` | 切到下一个公开演示任务 |
| `Esc` | 退出 |

每次按键都只产生一个最大 `1.2 cm` 的末端平移或 `0.08 rad` 的偏航增量；目标会被夹在工作空间内，IK 结果还会做关节限速。按住或快速重复按键仍可能导致碰撞，因此应先在空中移动到物体正上方，再下降、闭夹爪、抬起和放置。

## 与正式作业的关系

遥控和正式系统共用 `GraspEnv`、相机、控制周期、数值 IK、夹爪和物理碰撞。区别是：

- 遥控的目标识别由人眼完成，目标标签不能从脚本里读取；
- 作业策略必须在 `policies/student_policy.py` 中，从语言、RGB-D 和本体观测完成同样的目标选择与动作；
- 提交分数只由 `grasp-eval` 的自动评测、日志和物理成功谓词决定，遥控视频只可作为补充理解材料。

建议先完成一次 Task 1 的人工“靠近—闭合—抬起—移动—松开”操作，再实现自动状态机和视觉 grounding。这样能把模型错误、几何错误、夹爪接触错误和评测错误区分开。
